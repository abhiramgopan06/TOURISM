# 🌿 Forest Tourism Website

A simple and elegant forest tourism website built using HTML and CSS. This project showcases nature, adventure, and eco-tourism experiences through a visually appealing layout.

---

## 📌 Features

- 🌐 Responsive navigation bar  
- 🌿 Nature-themed homepage  
- 📖 "Our Story" section with images  
- 🏕️ Services section (trekking, camping, wildlife, etc.)  
- 📱 Social media icons (Font Awesome)  
- 🎨 Clean and simple UI design  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Font Awesome (for icons)  

---

git clone https://github.com/your-username/your-repo-name.git
